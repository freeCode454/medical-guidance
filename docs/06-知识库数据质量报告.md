## 2. 清洗与优化

- 全 sheet 去除首尾空白、连续空白与全角空格；
- 多值字段统一使用 `|`，去空值、去重并保持原顺序；
- 生成稳定的 `知识条目清单`，统一 `entry_code / kb_type / vector_collection / title / content / dept_code / icd10_codes / source / content_json`；
- `import_kb.py` 改为直接消费清单，避免每类数据各写一套解析逻辑；
- 原始数据备份后才写回，生成过程可重复。

## 4. 发现的问题（保留并标注，不静默改写）

- **跨科室重复疾病 18 个**：同一疾病出现在多个科室（如急性胃肠炎 DIG/GEN、急性心肌梗死 CAR/EMER）。这属于多科室视角，保留为不同条目，不强行合并。
- **ICD 章节冲突 12 个**：同一疾病/编码在不同行指向不同章节（如 A09.9 同时标为“消化系统”和“症状体征”）。已在数据质量报告中列出，未改医学编码。
- **指南标题重复 18 个**：同病不同科室的指南片段，保留科室差异。
- **字段缺失**：7 类核心知识 sheet 均无空单元格；科室引用无孤儿。
- 以上问题不影响导入，但正式用于临床前必须由医学人员复核。

## 5. 向量集合映射

| 知识类型 | Milvus 集合 | 标量字段 |
|---|---|---|
| DEPT_EXPERTISE | `kb_dept` | dept_code / dept_name / tenant_id |
| SYMPTOM_DISEASE | `kb_symptom` | dept_code / icd10_code / age_group / gender / tenant_id |
| GUIDELINE / GUIDELINE_REC | `kb_guideline` | icd10_code / evidence_level / pub_year / tenant_id |
| ICD-10 | `kb_icd10` | chapter / alias（全局共享，不分区） |
| DRUG_SAFETY | `kb_drug` | drug_name / taboo_type / tenant_id |
| CASE | `kb_case` | dept_code / diagnosis / tenant_id |

`ingest` worker 会为每个集合建表/建索引、分批 embedding、upsert，并删除已停用条目的陈旧向量。
